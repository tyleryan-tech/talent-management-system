# Prompt Templates

## 只读分析

```text
请阅读 AGENTS.md、docs/codex-knowledge/ 和 docs/system-analysis-for-codex.md。

先不要改代码。请分析这个需求：
<需求>

输出：
1. 当前系统相关实现
2. 相关 HRBP 业务规则
3. 代码规则与业务规则是否冲突
4. 数据、权限、审计、测试风险
5. 建议方案
6. 需要人工确认的问题
```

## 先方案后开发

```text
请阅读 AGENTS.md、docs/codex-knowledge/ 和相关代码。

我要实现：
<需求>

请先不要改代码，先输出：
1. 业务影响分析
2. 涉及的 HRBP 制度规则
3. 涉及的前端页面、store、后端 API
4. 数据模型变更
5. 权限和审计风险
6. 测试计划
7. 预计修改文件

等我确认后再开始开发。
```

## 精准开发

```text
根据已确认方案开始实现。

要求：
- 只改方案中列出的文件，除非发现必须补充的依赖文件。
- 不重写整个模块。
- 不把未确认制度硬编码。
- 高风险规则必须加测试。
- 完成后说明修改文件、测试结果和剩余风险。
```

## 自愈测试闭环

```text
实现后运行相关测试。

如果测试失败：
1. 读取失败日志
2. 判断是环境、测试用例还是业务代码问题
3. 只修复根因
4. 重新运行失败测试
5. 最多自动修复 3 轮
6. 仍失败时停止并报告剩余问题
```
